# 更新日志

## 1.0.0 (2026-07-19)

Nuxt Admin Template 初始版本。

### 功能

- **仪表盘**：系统数据概览、最近用户、快捷操作
- **用户管理**：完整 CRUD、状态切换、批量密码/状态重置、搜索分页
- **角色管理**：CRUD、权限分配、成员概览
- **权限管理**：按分类（页面/菜单/操作/功能）管理、CRUD
- **API 密钥管理**：密钥生成、权限绑定、使用统计、访问日志
- **API 访问日志**：按接口路径/方法/状态码筛选、分页
- **邮件模板**：CRUD、模板编辑
- **用户状态日志**：账户状态变更历史
- **数据库管理**：备份导出/恢复、序列重置、数据库重置
- **系统设置**：站点标题、Logo、描述、备案号、登录背景、注册开关
- **个人设置**：个人信息、密码修改、外观、通知

### 技术

- Nuxt 4 + Vue 3 + TypeScript
- shadcn-vue + TailwindCSS 4
- Drizzle ORM + PostgreSQL
- RBAC 权限系统（页面/菜单/操作/功能）
- JWT 认证、HttpOnly Cookie
- 暗色模式
- 响应式侧边栏布局
- 国际化文档（英文 + 中文）
