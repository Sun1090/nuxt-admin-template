# 技术栈说明

## 核心框架
- Nuxt 4 - 全栈 Vue 框架 (SSR/SSG)
- Vue 3 - 前端框架
- TypeScript - 类型系统

## UI 与样式
- shadcn-vue - UI 组件库
- TailwindCSS 4 - 原子化 CSS 框架
- reka-ui - 无障碍组件库
- Lucide Vue - 图标库
- Radix Icons - 图标库

## 后端与数据库
- Drizzle ORM - 类型安全的 SQL ORM
- PostgreSQL - 主数据库
- Redis - 缓存/会话存储（可选）

## 认证与安全
- bcrypt - 密码加密
- jsonwebtoken - JWT 认证

## 数据处理
- @tanstack/vue-table - 高性能表格
- xlsx - Excel 文件处理
- @unovis/vue - 数据可视化

## 表单验证
- vee-validate - 表单验证
- zod - Schema 验证

## 开发工具
- Pinia - 状态管理
- VueUse - Vue 组合式工具集
- Vue Sonner - Toast 通知
- @nuxtjs/i18n - 国际化（vue-i18n）
